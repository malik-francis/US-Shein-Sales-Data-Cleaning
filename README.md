# MySQL Sales Data Cleaning Workflow

This project demonstrates a practical workflow for cleaning and transforming raw sales data using MySQL. It covers common data quality issues such as inconsistent formatting, missing values, and extracting structured information from semi-structured fields.

I did this project to practice different SQL functions and to showcase my skills which inviolves:

Removing duplicates

Standardizing formats

Extracting structured data from text fields

Handling missing values

Steps to run script.

1. Import the sample data into your MySQL database.
2. Run the provided SQL scripts in order.
3. Review the cleaned data in the resulting table.
